## 11. Exact own-reach expectation feasibility

Workflow `31367407567`, evidence `a16e043fffda04f2c2fa228611e3e352d7ca39b8`.

Four unique HU deals, both target players:

- exact nodes `1,265,152`
- target-state samples `188,440`
- unique raw observations `116,192`
- exact phase `4.95 s`
- max depth `45`

Sampled own-reach support coverage on those same exact trees:

- 1 trajectory: `0.301%`
- 4 trajectories: `0.803%`
- 8 trajectories: `2.107%`

The result explains why adding unique deals can be inefficient: each deal has enormous action-path support, while the recovered estimator samples only one target-player path. Exact expectation is mathematically feasible at small scale but would produce tens of millions of samples at 640 roots, so it remains a versioned estimator-design option requiring bounded-memory/checkpoint redesign.

Relative iteration-2 strategy-support metrics versus baseline:

- `strategy_x4`: Jaccard `0.9280x`, weight coverage `1.4033x`, shared-target TV `0.9918x`
- `advantage_x4`: Jaccard `1.1131x`, coverage `1.4118x`, target TV `0.8769x`

Persisted diagnosis: **`ADVANTAGE_EXTERNAL_SAMPLING_VARIANCE_MATERIAL`**.

The key interpretation is upstream versus downstream variance. More own-reach trajectories strongly improve support under a fixed policy, but if the policy being sampled is already different because noisy Advantage estimates changed regret matching, merely recording that policy more densely cannot repair the upstream disagreement. Repeated Advantage trajectories directly reduce that upstream estimator noise, which then propagates into a much larger fitted-policy stability improvement.

Shared candidate controls:

The enlarged reservoir is deliberate: path replication must not be accidentally neutralized by Algorithm-R downsampling to the previous 100k cap before its effect is evaluated.

`advantage_x4` is the cleaner isolated candidate and had the better p95 at 256 roots. `both_x4` had the best mean and is being run in parallel because both frozen cross-seed gates matter. A gate pass will **not** immediately close R7.3: the changed replication/RNG contract would first be versioned into checkpoint/resume semantics and recertified for deterministic continuous versus stop/restore/continue behavior.

## 14. Current decision state

R7.3 remains **FAIL / ACTIVE**; R7.4 and R8–R12 remain blocked.

Dominant explanations materially narrowed or rejected:

- simple lack of unique roots;
- root card/chance variation;
- card/suit representation alone;
- training/traversal RNG bookkeeping coupling;
- AveragePolicy optimizer initialization alone;
- insufficient Advantage fitting alone.

The strongest remaining causal mechanism is **external-sampling Advantage path variance**, with own-reach support fragmentation as a secondary but proven variance source. The current parallel 640 run tests whether independent path replication is enough at acceptance scale. If it is not, the next target is estimator design (paired/common-random-number, stratified/antithetic opponent sampling, or partial enumeration), not another raw-root increase.
