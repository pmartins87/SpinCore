## Conceptual problem found during review

V1 built a **different conditional target reference for Stage A and Stage B**.

Opponent hidden hands were weighted by each stage's own self-play behavior likelihood for the observed public path.

That is useful for asking:

> what does each stage's own training process believe the conditional target should be?

But it is **not the correct common benchmark reference** for comparing Stage A and Stage B on states generated by the fixed JAMMER opponent.

The weak-baseline JAMMER rule is:

1. ALL_IN if legal;
2. otherwise CHECK_CALL if legal;
3. otherwise FOLD if legal;
4. otherwise maximum legal action.

This rule depends only on the public legal-action set. It does **not** depend on the opponent's private cards.

Therefore conditioning on the fact that JAMMER shoved does not reweight its hidden-card distribution.

For the actual Jammer benchmark state, the opponent-hand posterior remains uniform over compatible hands.

## Why this matters

Using stage-specific self-play posteriors can make Stage A and Stage B appear to have different target references even though:

- they are on the same observable state;
- they have the same hero cards;
- the benchmark opponent policy is fixed and hand-independent.

That contaminates direct A-vs-B error comparisons.

The V1 findings are therefore retained as descriptive diagnostics, but they are **not sufficient to authorize K4 training**.

## Corrected V2 reference

V2 uses one common Jammer-conditioned reference for each forensic state:

- uniform compatible opponent hands;
- uniform future boards;
- same reference target for Stage A and Stage B.

Because the opponent is already all-in at the anchor, there is no future opponent action to integrate.

For each explicit hidden deal, V2 computes the target with both Stage A and Stage B runtimes and asserts numerical equality.

If that assertion fails, the causal interpretation stops immediately.
